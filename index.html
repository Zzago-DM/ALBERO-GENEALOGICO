⚠ Il token resta salvato solo in questo browser e non viene mai caricato online. Per sicurezza usa un token «fine-grained» limitato a un solo repository, con permesso Contents: Read and write.

Per creare il token: su GitHub apri Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. In «Repository access» scegli solo il repository dei dati; in «Permissions» imposta Contents: Read and write; genera e copia il token (inizia con github_pat_).
